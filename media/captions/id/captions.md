## Post 1 — Modul 1: Konektivitas Bluetooth

Tahu nggak, nama "Bluetooth" itu diambil dari nama Raja Viking? 👑

Raja Harald "Bluetooth" Gormsson dikenal karena menyatukan Denmark dan Norwegia — dan nama itu dipakai untuk teknologi yang "menyatukan" berbagai perangkat lewat satu sinyal nirkabel.

Di Modul 1 praktikum IoT IRIS, mahasiswa belajar dua sisi Bluetooth: **Bluetooth Classic** (Master-Slave lewat serial) dan **Bluetooth Low Energy/BLE** — materi baru tahun ini — yang dirancang hemat daya untuk sensor-sensor IoT.

## Post 2 — Modul 2: Komunikasi WebSocket dengan Server Lokal

HTTP itu kayak kirim surat: tanya, jawab, selesai. Tapi gimana kalau datanya harus terus mengalir real-time? 💬

Jawabannya: **WebSocket**. Sekali koneksi terbuka, data bisa mengalir dua arah terus-menerus tanpa harus "kirim surat" berulang-ulang.

Di Modul 2, mahasiswa membangun sendiri server lokal berbasis Raspberry Pi 3B untuk menerima data real-time dari ESP32/ESP8266 — pembaruan besar dari tahun lalu yang masih pakai Firebase/Kodular.

## Post 3 — Modul 3: Konektivitas MQTT

Bayangkan satu sensor bisa "didengar" banyak aplikasi sekaligus — tanpa sensor itu tahu siapa saja yang mendengarkan. Itulah MQTT. 📶

Protokol publish-subscribe ini jadi favorit dunia IoT karena super ringan. Di Modul 3, mahasiswa memprogram **Raspberry Pi Pico W** dengan MicroPython, terhubung ke broker **Eclipse Mosquitto** yang mereka jalankan sendiri secara lokal.

## Post 4 — Modul 4: Komunikasi Long Range (LoRa)

Dari meja praktikum sampai berkilometer jauhnya — tanpa boros baterai. 🛰️

Modul 4 tahun ini benar-benar baru: mahasiswa belajar **LoRa** (modulasi radio jarak jauh, hemat daya) menggunakan board kustom **Cosmic LoRa Aurora V2** — lalu langsung mengujinya lewat permainan perburuan langsung, melacak beacon tersembunyi hanya dari kekuatan sinyalnya.

Di Indonesia, jalur LoRa praktikum ini beroperasi di pita 920–923 MHz (AS923-2) — cocok untuk komunikasi jarak jauh dengan konsumsi daya minim.
