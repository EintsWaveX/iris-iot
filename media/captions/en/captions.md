## Post 1 — Module 1: Bluetooth Connectivity

Did you know "Bluetooth" is named after a Viking king? 👑

King Harald "Bluetooth" Gormsson was known for uniting Denmark and Norway — and that name was chosen for a technology built to "unite" devices under one wireless signal.

In Module 1 of the IRIS IoT practicum, students learn both sides of Bluetooth: **Bluetooth Classic** (Master-Slave over serial) and **Bluetooth Low Energy (BLE)** — new material this year — built to sip power for IoT sensors.

## Post 2 — Module 2: WebSocket Communication with a Local Server

HTTP is like sending a letter: ask, answer, done. But what if your data needs to flow in real time? 💬

Enter **WebSocket**. Once the connection opens, data flows both ways continuously — no more sending a new "letter" every time.

In Module 2, students build their own local server on a Raspberry Pi 3B to receive real-time data from an ESP32/ESP8266 — a major upgrade from last year's Firebase/Kodular setup.

## Post 3 — Module 3: MQTT Connectivity

Imagine one sensor being "heard" by multiple apps at once — without ever knowing who's listening. That's MQTT. 📶

This publish-subscribe protocol is an IoT favorite because it's so lightweight. In Module 3, students program a **Raspberry Pi Pico W** in MicroPython, connected to a self-hosted **Eclipse Mosquitto** broker.

## Post 4 — Module 4: Long Range Communication (LoRa)

From the workbench to kilometers away — without draining the battery. 🛰️

Module 4 is brand new this year: students learn **LoRa** (long-range, low-power radio modulation) using the custom **Cosmic LoRa Aurora V2** board — then put it to the test in a live hunt game, tracking down a hidden beacon by signal strength alone.

In Indonesia, this practicum's LoRa link runs on the 920–923 MHz band (AS923-2) — ideal for long-range communication on minimal power.
