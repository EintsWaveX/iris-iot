## Contracts
`GET lc` answers the seat's whole state; spins are drawn on the server and the animation lands on the answer. The seat's boards use the seat's own hotspot first (ruling 2026-10-24); a changed hotspot needs only Kompilasi Ulang. A board's token expiry is the slot end plus 8 hours, so `iris_seat.h` is the same between compiles. HTTP and WebSocket seats start on the HTTP template (variant `http`); switching asks first when any board's code was edited (`kode_berubah` unless `replace: true`). Re-roll: the same protocol keeps the candidate's code; a new protocol or topic puts the template back. Deleting every topic in the bank brings the six defaults back. Grading is open once the Live Coding timer has started; **Finalkan closes it** only when 13's freeze exists (there is no `rec_score_freeze` yet). The `bank` right is told the other sheets in full after Finalkan: **13 must pass `full` to `peerView`**. `rec_mqtt_job` is an extra table in 0052; passwords wait sealed (`rahasia.ts`, label `rec-mqtt-job`) and are emptied when the job is done.
