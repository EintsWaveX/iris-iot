## Contracts
- **API additions** (all covered by tests in `api/__tests__/recruitment-api.test.ts`):
  - `GET calendar` now answers a **visitor** with the public events only (same `visibleEvents` filter: no internal, no own or offered). The visitor's `/recruitment` page needs it.
  - `GET me` documents carry their own **`id`** (needed to open a file through `berkas`, which still answers 404 for anyone else's).
  - `GET committee` carries **`pool`** (active Asisten: `nim, nama, kode`) only for whoever holds the `board` or `seatKetua` right; on leave is not special-cased (user ruling).
- **Client library** `src/lib/recruitment/`: `client.ts` (`recGet`, `recPost` returning `{ ok:false, kode, status }` instead of throwing; `useRecBanner`, `useRecEdition`, `useRecCalendar`, `useRecMe`, `useRecCandidates`, `useRecCommittee`, all on siaran topics, no timers), `upload.ts` (`periksaLokal`, `kirimBerkas`: ticket, PUT with progress and retry, returns the ticket for `apply` or `document`), `panel-tab.ts`.
- **Siaran topics** `recedition`, `reccalendar`, `reccandidates` are subscribed; the `BELUM_DIDENGAR` exemption in `siaran-topik.test.ts` is gone.
- **Shell:** `<Base shell="rekrutmen">`. S2 and later pages (`/recruitment/test`, `/recruitment/qr`) should use it too. `AppNav.tsx` now exports `Avatar`.

## Where the real kit and the mockup disagree (took the kit)
- The Bulan and Agenda switch fills its row like every other switch on the site (Phase 9 rule), instead of sitting small in the card head.
- **Kelas is typed** in Daftar. The mockup read it from the account, but the Praktikan account only knows reguler or internasional, not an academic class like TK-48-01.
- **No XLSX download and no Panitia notes box** in Kandidat: no API for either in 02 (only the Admin's fix note exists). Add them with an API if wanted.
- **No template download links** in the upload slots: the user has not said where templates come from. `Slotnya` takes a `templateUrl` and shows the link as soon as there is one.
- Daftar's angkatan list is 2023 to 2026.
- The Ketua slot on the board: with the seatKetua right, drag the Ketua out to free the chair, then drop someone on the empty "Ketua" slot. (The mockup showed only the lock.)
