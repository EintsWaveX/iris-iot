## Editability principle (user, 14:36)
Anything that can reasonably be edited must be editable by Panitia (the right role), across the whole oprec web, not only the late stages: dates and windows, capacities, panel and PJ sizes, minutes, rubric rows and weights, question cards, thresholds and quotas, envelope wording, special-case rules, retention days, topics and submission limits, codes. Values live in editable data/config with a clear edit surface (a Template or Atur tab), a default, an audit note, and role limits. The agents must list every hard-coded value that should be editable and either make it editable or report it.
